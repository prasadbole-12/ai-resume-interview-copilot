# AI Resume & Interview Copilot

Status: Ongoing

## Overview

AI Resume & Interview Copilot is a backend application designed to help users improve their resumes and prepare for technical interviews through personalized feedback and interview question generation.

## Tech Stack

* Node.js
* Express.js
* MongoDB

## Planned Features

* Resume Upload and Storage
* Resume Analysis
* Interview Question Generation
* User Authentication
* Progress Dashboard

## Development Status

Currently under active development.
